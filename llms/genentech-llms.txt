# Genentech

> Genentech is a biotechnology company (founded 1976, South San Francisco; part of the Roche Group since 2009) that discovers, develops, and commercializes medicines. For developers it operates a public Developer Portal and Integration Marketplace exposing FHIR R4 "Universal API" (UAPI) services for Patient Support Services, plus a large open-source GitHub organization for computational biology and AI.

## APIs

- [Genentech Universal API (UAPI)](https://fhir.developer.gene.com/): FHIR R4 (v4.3.0) API for Patient Support Services — Access Solutions patient enrollment, Copay enrollment, Patient Foundation enrollment, and enrollment status queries. Registration-based via the Integration Marketplace with API keys + OAuth2/OIDC.
